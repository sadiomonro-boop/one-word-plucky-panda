A tiny program that writes the entrant's own make.fun username, `plucky-panda-24`, as a single word to `entry.txt` for the "One Word, One Username, One Reward" competition on make.fun. The program validates the handle (1–30 characters, no whitespace) and writes exactly those 15 characters — no trailing newline, no extra text.

## Run it

```sh
node main.ts
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory.
